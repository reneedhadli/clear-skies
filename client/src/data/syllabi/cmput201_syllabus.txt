CMPUT 201 — Practical Programming Methodology
University of Alberta · Fall Term · 3 credits
Instructor: Dr. Priya Raman
Office hours: Tuesday and Thursday, 2:00–3:00 pm, Athabasca Hall 3-41

COURSE DESCRIPTION
This course builds the habits behind reliable programs: testing, debugging, modular
design, memory management, and the C programming language. You will write more code
than in CMPUT 174 and learn how to reason about your own programs.
